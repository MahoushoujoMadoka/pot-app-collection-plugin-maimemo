# Pot-App [墨墨背单词](https://maimemo.com/) 生词本插件

## 功能

- **添加单词到墨墨云词本**: 将 Pot 中查询的单词一键添加到墨墨背单词的云词本中
- **自动创建云词本**: 如果指定的云词本不存在，会自动创建新词本
- **智能单词收录检测**: 自动检测单词是否已被墨墨词库收录
- **重复单词检测**: 自动检测单词是否已存在于云词本中

## 使用方法

### 安装 Pot

此插件为 [Pot App](https://github.com/pot-app/pot-desktop) 生词本插件，必须配合 [Pot App](https://github.com/pot-app/pot-desktop) 来使用

### 安装插件

1. 在 Releases 中下载最新的后缀为 `.potext` 的文件
2. 打开 Pot-服务设置-生词本-添加外部插件-安装外部插件
3. 选择刚刚下载的 `.potext` 文件
4. 填写插件的配置项:
   - **API Token**:从墨墨背单词应用获取的 64 位十六进制令牌
   - **词本标题**:要添加单词到的云词本名称(如果不存在会自动创建)
   - **是否启用单词检测**:选择是否检测单词是否被墨墨收录
5. 保存配置
6. 在查询界面中，点击下方的墨墨图标即可将单词添加到墨墨云词本
